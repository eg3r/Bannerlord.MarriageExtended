# MarriageExtended

A simple, lightweight mod for **Mount & Blade II: Bannerlord** that adds missing marriage features to the vanilla game.

Unlike other marriage mods that add extensive features or overhaul entire systems, MarriageExtended focuses on doing a few things well with minimal changes to vanilla gameplay.

## Features

### Core Features
- **Companion Marriages** – Arrange marriages for your companions (wanderers). In vanilla, only nobles can marry - this mod removes that restriction for recruited companions
- **Matrilineal Marriage** – Choose to have the groom join the bride's clan instead of the vanilla default (wife always joins husband's clan). This option appears in the barter screen when negotiating marriages

### Configurable Settings (via MCM)
- **Minimum Relations** – Adjust clan relations required for marriage (default: -25, vanilla: -50)
- **Marriage Costs** – Configure base costs, hero value factors, and clan tier modifiers
- **Minimum Dowry** – Set the minimum barter value for marriages
- **Matrilineal Cost Multiplier** – Adjust the cost of matrilineal marriages

## Why This Mod?

Vanilla Bannerlord is missing two simple marriage features: companions can't marry, and there's no way to keep the bride in her own clan. This mod adds both without unnecessary complexity.

If you want:
- ✅ Companion marriages without extra bloat
- ✅ Matrilineal marriage option (groom joins bride's clan)
- ✅ Minimal changes that feel close to vanilla
- ✅ Lightweight with no performance impact

Then this mod is for you.

## Compatibility

✅ **Save Compatible** – Can be safely added to existing saves without issues.

## Installation (manually)

1. Download the latest release
2. Extract to your `Modules` folder (`Steam\steamapps\common\Mount & Blade II Bannerlord\Modules`)
3. Enable the mod in the Bannerlord launcher

## Requirements

- Mount & Blade II: Bannerlord (v1.3.13+)
- [Harmony](https://www.nexusmods.com/mountandblade2bannerlord/mods/2006)
- [ButterLib](https://www.nexusmods.com/mountandblade2bannerlord/mods/2018)
- [MCM](https://www.nexusmods.com/mountandblade2bannerlord/mods/612)
- [UIExtenderEx](https://www.nexusmods.com/mountandblade2bannerlord/mods/2102)
